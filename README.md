# ASWF IG Live calendar file

`aswf-ig-live.ics` is served by GitHub Pages at
https://ivyleaguelawyer.github.io/aswf-ig-live-calendar/aswf-ig-live.ics with
`Content-Type: text/calendar`. The "Add to Calendar" button on the ASWF IG Live reminder page
(https://muse.ai/s/aswf-ig-live-reminder-wxh6wz8clxjxr8) links straight to it.

**To change the event:** edit `aswf-ig-live.ics` on `main` (DTSTART/DTEND in Pacific local time,
bump DTSTAMP to now in UTC, keep CRLF line endings and lines under 75 chars). Pages redeploys in
1–3 minutes. The reminder page needs no change unless its visible date text should also update.

Keep this repo public and do not delete it while the reminder page is live.
Full procedures: `flowb-fix/MAINTENANCE.md` in the SEMA 2026 QR Code Plotter Giveaway Drive folder.
